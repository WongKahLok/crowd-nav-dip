# Every experiment of the project and the settings it runs under.
# crowd_nav/exp.sh reads this table, so running, filming and rule-checking an
# experiment always use exactly the same settings.
#
# Settings shared by every experiment (set in exp.sh):
#   100 trips per map per ship count, always trips (seeds) 0-99, so every experiment
#   faces the same situations; 10 trips run at once on 10 CPU cores; a trip gives up
#   after 500 steps (125 s). Rule checks replay 25 trips per map and count another
#   ship as a risk within 10 m and 20 s.
#
# Every experiment runs the 8-ship trips, so any two can be compared. The four
# baselines also run lighter and heavier traffic, because the report needs three
# traffic levels (SF only fits about 12 ships; HT fits about 25).
#
# Model folders are created from output-trained automatically when missing:
#   output-visible   other ships can see our ship and move out of its way
#   output-slowturn  our ship turns at 20 deg/s instead of 60
#
